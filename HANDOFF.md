## Architecture (quick map)
- Ingest: Apps Script + a Google Ads-bound script write GA4/Ads to a staging Google Sheet;
  Python reads it via gspread. `--dummy-data` bypasses all of this with seeded fixtures.
- `config/dashboard.yml` = the contract (markets, channels, KPIs, thresholds, delivery).
- `transform/` normalize_markets (Ohio before Colorado!), classify_branded, aggregate,
  join_costs, attribute_np (proportional NP attribution + `compute_kpis`), deltas.
- `render/renderer.py` builds all pages + Chart.js specs (expanded by `static/charts.js`);
  templates are self-contained Jinja (`_base.html`, `_macros.html`) using the client-approved
  design in `render/static/cpi-brand.css`.
- `publish/deploy.py` force-pushes `output/` to `gh-pages` (orphan, `.nojekyll`, bot commit).
- Workflow: `.github/workflows/refresh.yml` (Mon 7am CT cron + manual). Deploy needs
  `GITHUB_TOKEN: ${{ github.token }}` in the run step (already wired).
- v2 blocks (`by_campaign`, `by_market_campaign_type` heatmap, `exceptions`) are computed in
  `compute_kpis` from the classified Google Ads frame + period deltas; renderer only formats.
  Deltas use a prior snapshot if present, else within-run month-over-month.
